# babai_gi — Babai's quasipolynomial Graph Isomorphism algorithm in Python

A faithful, pure-Python (standard library only) implementation of László Babai's
quasipolynomial-time algorithm for **String Isomorphism** in Luks's framework,
following

* **[Babai]** L. Babai, *Graph Isomorphism in Quasipolynomial Time*, arXiv:1512.03547v2
  (January 2016); section / theorem numbers below refer to this version;
* **[HBD]** H. Helfgott, J. Bajpai, D. Dona, *Graph isomorphisms in quasi-polynomial time*,
  arXiv:1710.04574 (Séminaire Bourbaki exposition, which incorporates Babai's January-2017
  fix of the primitive case of Coherent Split-or-Johnson; section / proposition numbers refer
  to this text).

Graph Isomorphism is solved through the standard reduction (Babai Sec. 1.1.1): a graph on
`V` is the 0/1 string on `Ω = binom(V,2)` acted on by `Sym(V)` in its induced action on pairs.
The algorithm returns the **full coset of isomorphisms** `ISO_G(x,y) = Aut_G(x)·ρ`
(generators of `Aut_G(x)` and a representative), hence also `|Aut(X)|`.

`networkx` is **not** used by the algorithm; it appears only in the tests, as a graph
generator and as the independent reference isomorphism checker.

## 1. The theorem implemented, and the bound proved for this code

**Theorem (Babai Thm. 1.1.1 / Cor. 1.1.2, HBD Main Theorem).**
Given a permutation group `G ≤ Sym(Ω)` by generators and two strings `x, y : Ω → Σ`,
the set `ISO_G(x, y) = {σ ∈ G : x^σ = y}` (a coset of `Aut_G(x)`, or empty) can be
computed in time `exp(O((log n)^3))`, `n = |Ω|` (HBD Appendix A). Consequently Graph
Isomorphism for graphs with `v` vertices is decidable in time `exp(O((log v)^3))`, and the
whole automorphism group is obtained.

The implementation computes exactly this object: `Solver.iso(G, x, y)` returns a
`Coset` (a `PermGroup` generated by generators of `Aut_G(x)` and a representative `ρ`)
or `None`; `graph_isomorphism` / `graph_automorphisms` wrap the reduction.

**What is proved about this code** (default parameters `Params.paper()`):

* **Correctness** (`CORRECTNESS.md`): the output is `ISO_G(x, y)` for every input, every
  call terminates, and no fallback and no internal guard can be reached (so no step outside
  the papers' procedures ever runs).
* **Running time** (`PROOF.md`), counted in *operations* (one CPython 3.13 bytecode
  instruction; unit-cost integer arithmetic; dictionary operations one plus the hashing of
  the key; built-ins one per element they touch; `PROOF.md` Part I): `string_isomorphism` on `n` points executes at most `2^{U(log₂ n)}` operations,

      U(X) = b* X³ + X ρ(X) + 2X² + E(X) + U₀,   b* = (S₂ + δ)/(3δ²) = 2.6593095…,

  with `δ = log₂(3/2)`, `S₂ = 1/2 + π²/6`, `ρ(w) = 5w log₂²w + 3w log₂ w + 12w`,
  `E(X) = ∫₀^X (3u²/log₂²(u+4) + 11u + 60) du` (so `U(X) = b*X³ + 5X² log₂²X + 3X² log₂X + 39X²/2 + 60X + 3I(X) + U₀` with
  `I(X) = ∫₀^X u²/log₂²(u+4) du` for `n ≥ 2`, and `PROOF.md` Lemma 4.2 bounds
  `3I(X) ≤ X³/log₂²(X+4) + 1.17 X³/log₂³(X+4)`, within 1% of `3I(X)` for `X ≥ 84`),
  and `U₀` from `PROOF.md` §13. For graphs on `v` vertices the leading term is
  `(2A + 3B) log₂³ v` with `2A + 3B = 6.1733746…`.
* **The form `a · 2^{b log₂^c n}`**: `c = 3`; the infimum of the admissible `b` is
  `b* = 2.6593095…` and is not attained (`U(X) − b*X³ → ∞`, so no finite `a` works at
  `b = b*`); for each `b > b*` the smallest `a` with `2^{U(log₂ n)} ≤ a · 2^{b log₂³ n}` for

  §13.3 proves lower and upper bounds for `M(b)`:

  the table the large `a(b)` comes from the term `5X² log²X` (the sum of the Split-or-Johnson
  choice counts along a chain of colourings); as `b → b*` the maximum moves to larger `X`,

Every step of the time proof is a proof from the code (per-function bounds in
`docs/bounds/`, combined in `PROOF.md` Part III) or a cited theorem of the papers; the
finitely many numerical inequalities are checked with exact interval arithmetic by
`python -m babai_gi.timebound` (also run by `tests/test_bounds.py`).

**Default parameters = the papers' thresholds**, with three changes that keep the papers'
proofs valid and lower the constant `b`: `α = 2/3` (the smallest value the Extended Design
Lemma and Split-or-Johnson admit; Babai states `3/4`), the arity of the `d`-ary structure in
Bipartite Split-or-Johnson is `d = 2s` with the smallest `s` such that
`binom(|V_2|, s) > |V_1'|` (HBD take `s = 3⌈l⌉`; the Ray-Chaudhuri–Wilson argument needs only
the inequality), and HBD's "`|V_2|` small" step (individualise all of `V_2` when
`|V_2| ≤ (6 log|V_1|)^{3/2}`) is not used — with the arity rule the proof does not need it,
and it would add a `|V_2|!` factor. All threshold comparisons are exact integer arithmetic.
`Solver()`, `graph_isomorphism`, `string_isomorphism` and the CLI use `Params.paper()`
(`babai_gi/main.py`): the Cameron–Maróti bound `|Ḡ| < m^{1+⌊log₂ m⌋}` decides between
enumeration and Johnson identification (Babai Thm. 3.2.3, Reduce-to-Johnson line 5),
`Sym(Γ)` is enumerated when `|Γ| < ℓ(n) = 10·k(n)` with `k(n) = max(9, ⌊log₂ n⌋ + 3)` the
smallest test-set size admitted by the Unaffected Stabilizer Theorem (Thm. 8.3.5,
Thm. 10.1.3: `max(8, 2 + log₂ n) < k ≤ m/10`), and Local Certificates use `k = k(n)`. At the
sizes a Python implementation can process these thresholds degenerate to what the papers
prescribe there — enumeration of `Sym(V)`: by line 5 for graphs with fewer than 22 vertices
(`v! < binom(v,2)^{1+log₂ binom(v,2)}`), and by the `|Γ| < ℓ(n)` rule up to ~160 vertices
(`ℓ(binom(v,2)) > v` for `v < 160`); feasible in Python up to 8–9 vertices — which is why the
test battery exercises the Johnson-case machinery with `Params.small_scale()` (Sec. 5,
Sec. 7 item 1).

## 2. Algorithm walkthrough (what the code does on an input)

`Solver.iso` (`babai_gi/main.py`) is Babai's **Procedure Reduce-to-Johnson** (Sec. 3.3)
followed by the **Master Algorithm** (Sec. 12):

1. **Trivialities** (Reduce-to-Johnson line 1–2). If every generator of `G` fixes `x`,
   `ISO_G(x,y)` is `G` or empty. If `|G| ≤ C_0` (`Params.brute_force_order`), exhaustive
   search along the stabiliser chain (`brute_force`, `_chain_search`).
   For `x ≠ y` the solver first finds one isomorphism and then `Aut_G(x)`; the answer is
   `Aut_G(x)·ρ` (eq. (12)/(13)).
2. **Intransitive `G`** → Luks's **Chain Rule** over the orbits (Prop. 3.1.7): windows are
   processed one by one, each by a recursive call on the restricted group
   (`chain_rule`, `iso_window`, `WindowLifter`: Obs. 3.1.10 "reducing to the window"
   with the kernel `G_(Δ)` added back when lifting).
3. **Transitive `G`, giant** (`G ≥ Alt(Ω)`): the trivial Johnson case `t = 1`
   (Master Algorithm line 4): isomorphism depends only on letter multiplicities
   (`trivial_case`, with the parity bookkeeping for `Alt`).
4. **Transitive `G`**: a minimal block system (maximal blocks, Atkinson's algorithm,
   `PermGroup.minimal_block_system`), the primitive quotient `Ḡ` acting on the `m` blocks.
   * If `|Ḡ| < m^{1+log₂ m}` (Cameron–Maróti bound, Thm. 3.2.3; `Params.luks_threshold`,
     which `Params.small_scale()` additionally caps at 20000): **strong Luks reduction**
     (Thm. 3.1.8): enumerate the `|Ḡ|` cosets of the kernel `N` and recurse on `N` (whose
     orbits are the blocks) (`strong_luks`).
   * Otherwise `Ḡ` is a Cameron group (Thm. 3.2.1, Def. 3.2.2). The code identifies it
     combinatorially (`johnson.py`): a **Johnson group** `S^{(t)}(Γ)` / `A^{(t)}(Γ)`
     (`recognize_johnson`, after HBD Sec. 2.8 / [BLS]) or the **product action**
     `S_k^{(t)} wr S_s` on `binom(k,t)^s` points, `s ≥ 2`, any `t ≥ 1` (`recognize_cameron`;
     `t = 1` is the Hamming scheme, `recognize_hamming`): the orbital that is the Cartesian
     product of `s` Johnson graphs `J(k,t)` gives the layers, their parallel classes are the
     coordinates, the action on the coordinates is the epimorphism `Ḡ → S_s` whose kernel
     `N` (index `≤ s!`, Prop. 3.2.5) acts on the fibers of a coordinate as a Johnson group
     (verified with `recognize_johnson`). A weak Luks reduction over the `≤ s!` cosets of `N`
     passes to `φ^{-1}(N)` (`cameron_reduction`, Reduce-to-Johnson line 6); the recursion on
     it finds the Johnson quotient on the fibers. A primitive quotient above the bound that
     is neither (possible only for `m < 25`: `M_12`, `M_24`, Thm. 3.2.3 / Maróti) is
     enumerated — its order is bounded by the absolute constant `24!`.
   * This yields the **Johnson case** (Def. 3.4.1): a giant representation
     `φ : G → Sym(Γ)`, `|Γ| = m`, with standard blocks `B_T`, `T ∈ binom(Γ,t)`
     (Thm. 8.5.1). If `m < ℓ(n)` (`Params.gamma_threshold`; paper: `ℓ(n) = 10·k(n)`,
     Sec. 1) the quotient `S^{(t)}(Γ)` is simply enumerated (Babai Sec. 1.2 / 3.4:
     "brute force enumeration over `Sym(Γ)` at a multiplicative cost of `ℓ(n)!`").
5. **Johnson case, `G` primitive on `Ω = binom(Γ,t)`, `t ≥ 2`** (Master Algorithm lines 5–7):
   `x` is an edge-coloured `t`-uniform hypergraph on `Γ`.
   * relative symmetry defect `< 1/2` (a twin class `C`, `|C| > m/2`, Prop. 2.6.4): the
     canonical partition `{C, Γ∖C}` is aligned and pulled back (Cor. 9.0.9 realised through
     `branch` and the general recursion on `φ^{-1}(Sym(C)×Sym(Γ∖C))`);
   * otherwise `t`-WL refinement (`wl.py`: functors `F_2`, `F_3` of HBD) and the **Extended
     Design Lemma** (Thm. 7.3.3, `design.py`): Design Lemma (Thm. 6.1.1 / HBD Prop. 4)
     → either a colouring with no `α`-dominant class (`α = 2/3`), or a dominant class with a non-clique
     coherent configuration → components (equipartition) or **UPCC Split-or-Johnson**
     (Thm. 7.3.1, `soj.py`).
6. **Johnson case, `G` imprimitive** (lines 8–12): **AggregateCertificates** (Thm. 10.2.1,
   `imprimitive_johnson`, `aggregate`): **Local Certificates** (Thm. 10.1.3, Procedure
   LocalCertificates, `certificates.py`) for all test sets `A ∈ binom(Γ,k)`; the group `F`
   generated by the certificates of fullness `K(A)`; then HBD Sec. 6.2 / Babai Sec. 10.2:
   Case 1 (`|supp F^Γ| ≥ m/2`, no orbit `> m/2`): colouring by orbit length;
   Case 2a (orbit `Φ`, `F^Φ ≥ Alt(Φ)`): pullback and the **top action** (Sec. 9,
   Cor. 9.0.6–9.0.9, `top_action`); Case 2b (`F^Φ` not a giant): individualise points until
   the stabiliser is not doubly transitive and hand the Schurian coherent configuration to
   Split-or-Johnson (`case_2b_structure`); Case 3 (`|supp| < m/2`): the canonical `k`-ary
   relation obtained by **comparing certificates** (Prop. 10.1.11, `LocalCertificates.compare`,
   HBD eq. (10)–(12)) → Extended Design Lemma (`case_3`).
7. **Align** (Sec. 11.1): every canonical structure found for `x` is recomputed for `y`
   along *every* sequence of the non-canonical choices (Prop. 4.0.4, the "multiplicative
   cost"; `structure.py`: `RecordingChooser`, `ReplayChooser`, `enumerate_runs`), the two
   structures are aligned by a permutation of `Γ` lifted to `G` (`align`, `GroupWithAction.lift`),
   `G` is replaced by `φ^{-1}(Aut(X(x)))` and the Master Algorithm restarts on the smaller
   group (`Solver.branch`). Branches whose choice sequence lies in the orbit of an already
   processed one under the automorphisms found so far are skipped (they only give translates
   of the same coset).

## 4. How the time bound is proved (summary of `PROOF.md`)

1. **Cost of one call of each function** (`docs/bounds/*.md`): from the instruction profiles
   of `babai_gi/opcount.py` (Lemma 1.1: `outside + Σ_loops cycle·(iterations + entries) +
   entry·entries`, checked against `sys.monitoring` counts by `tests/test_opcount.py`), an
   iteration bound with proof for every loop, and the callees' bounds. Calls of
   `Solver.iso` are listed separately; they are the recursion.
2. **A potential on states** `(G, tower of block systems)`: for each level of the tower
   with ratio `r = 2^z`, cumulative size `2^Y` and section degree `μ` (the largest `μ` such
   that `Alt(μ)` is a section of the level's group; `w = log₂ min(r, μ)`), the term
   `F(z, w, Y) + zρ(w) + 2z²`, `F(z, w, Y) = z(Aw² + Bw(Y − (z − w)/2))`, plus `E(log₂ n)`.
   Subgroups, restrictions and the extension of the tower do not increase it.
3. **Induction**: every `_solve` node costs at most `λ·2^{potential}` (`λ` the letter size).
   Each node type (brute force, giant, strong Luks, Cameron reduction, Johnson case with its
   local certificates, comparisons and the branch over choice sequences) lowers the
   potential of every recursive leaf by at least `log₂` of its multiplicity plus 4: the
   multiplicity of the branch is `2^{σ(X, y)}`, `σ = (k − 2)y + βy² + R(y)`, `y = log₂|Γ|`,
   `β = S₂/δ` (the Design-Lemma prefixes of Split-or-Johnson summed along its recursion), and
   a colouring step shrinks `|Γ|` and the window by `3/2` (Babai Lemma 5.2.1). Choosing
   `B = 1/(2δ)` and `A = (β − 1/2)/(3δ)` makes the two leading terms of these inequalities
   cancel exactly; the rest is verified by `timebound.py`.
4. **Chain rule and caches**: the solver stores `Aut_G(x)` and the stage groups of the Chain
   Rule, so in a nested chain of Chain-Rule calls every transitive leaf is solved once
   (Lemma 7.1); without this a factor 2 per nesting level would appear.

## 5. How to run and test

```sh
python -m pytest -q                              # default battery (about 5 min, incl. the exact checks)
python -m pytest -q --runslow                    # also the slow cases
python -m babai_gi.timebound                     # the numerical checks of the time proof (about 2 min)
python -m babai_gi g1.txt g2.txt                 # CLI, papers' thresholds (<= ~9 vertices)
python -m babai_gi --small-scale g1.txt g2.txt   # CLI, small-scale thresholds
```

Edge-list format: a first line `n [m]`, then one edge `u v` per line (0-based), `#` comments.
The CLI prints `ISOMORPHIC` followed by the vertex map `u->v …`, or `NOT ISOMORPHIC`
(exit code 1), plus a line with the running time, the preset and the solver's branch counters.

Python API:

```python
from babai_gi import graph_isomorphism, graph_automorphisms, string_isomorphism, Params
iso = graph_isomorphism(edges1, n, edges2, n)          # dict vertex -> vertex, or None  (Params.paper())
gens, order = graph_automorphisms(edges, n, params=Params.small_scale())   # generators and |Aut|
coset = string_isomorphism(G, x, y)                    # G: babai_gi.group.PermGroup; Coset or None
```

| `α` (Thm. 7.3.3, case 2b), Design-Lemma `α` on `V_2` | `2/3`, `2/3` | `2/3`, `2/3` |
| fallbacks (exact but outside the papers) | unreachable; would raise `TheoremViolation` | allowed |

Both presets accept overrides (`Params.small_scale(local_k=3)`); the constructor's keyword
defaults are the paper values. Why two presets: with the paper values, `ℓ(n) ≥ 90` (indeed
`ℓ(binom(v,2)) > v` for graphs with `v < 160` vertices) and `v! < binom(v,2)^{1+log₂ binom(v,2)}`
for `v < 22`, so on every input a pure-Python implementation can process the papers prescribe
plain enumeration of `Sym(V)` (`8! = 40320` recursive calls take 0.3 s, `10!` takes 85 s) and
the Johnson-case machinery (Design Lemma, Split-or-Johnson, Local Certificates) never
executes. The small-scale preset is the same algorithm with constants low enough for every
branch to run on 8–28-vertex graphs; the papers' theorems do not apply at those sizes, which
is why the code verifies what they would guarantee (Sec. 7).

## 7. Deviations and limitations

Everything below is a deliberate, documented difference from the papers. None of them
affects the correctness of the output (the result is always exactly `ISO_G(x,y)`).

1. **Two parameter presets; the paper preset is feasible only on tiny inputs.** The default
   `Params.paper()` follows the papers' thresholds (Sec. 1, Sec. 5), and with them every
   input a Python implementation can process is handled by the enumerations the papers
   prescribe at small sizes: Reduce-to-Johnson line 5 enumerates `Sym(V)` for graphs with
   fewer than 22 vertices (`v! < binom(v,2)^{1+log₂ binom(v,2)}`), and the rule
   `|Γ| < ℓ(n)` enumerates `Sym(Γ)` for `|Γ| < 90` in general and up to `v < 160` for the GI
   reduction (`ℓ(binom(v,2)) = 10(⌊2 + log₂ binom(v,2)⌋ + 1) > v`), so no Johnson case
   reachable in Python is processed by the Design Lemma or Local Certificates. Consequently the
   Johnson-case machinery is *tested* with `Params.small_scale()` (`k = min(max(3, ⌈log₂ n⌉),
   m − 2, 4)`, `ℓ = 8`, quotient enumeration capped at 20000, `|V_2| ≤ 3`, arity `≤ 4`;
   same `C_0 = 5040`), i.e. with constants below the papers' thresholds, and the paper preset
   is tested end-to-end only where it is feasible (`tests/test_presets.py`: graphs with
   `≤ 8` vertices, `|Γ| ≤ 7`, `M_12`). The quasipolynomial bound (Sec. 4) is a statement
   about the default preset; the small-scale preset is the same algorithm with other constants
   and the same exact fallbacks. The brute-force constant `C_0` and HBD's "`|V_1| ≤ c`"
   constant (`SOJParams.small_v1 = 6`) are unspecified absolute constants in the papers.
2. **Fullness below the threshold (small-scale preset only).** With `k` below the threshold
   of Thm. 8.3.5 the group `K(A) = H(W)_(Ω∖W)` need not map onto `Alt(A)`. The code *verifies*
   `K(A)^A ≥ Alt(A)` and, when the verification fails, finishes the procedure on the full
   window `W = Ω` (`lc_fallback_full_window` counter), which makes the fullness decision exact
   at a cost that the paper's analysis does not cover (it is bounded by `m^{O(m)}`,
   quasipolynomial in the regime `m = O(log n)` in which the paper enumerates `Sym(Γ)`
   anyway). With `Params.paper()` the hypothesis `k > max(8, 2+log₂ n)` holds and the
   verification cannot fail.
3. **Unrecognised primitive quotients are enumerated.** Cameron groups with `s ≥ 2` are
   recognised for every `t ≥ 1` (`recognize_cameron`, Sec. 2 step 4), so above the
   Cameron–Maróti bound the only quotients the identification can reject are the exceptions
   of Thm. 3.2.3 for `m < 25` (`M_12`, `M_24`), which are enumerated (cost bounded by an
   absolute constant). Should a quotient of degree `m ≥ 25` and order `≥ m^{1+log₂ m}` ever
   be rejected — impossible by Thm. 3.2.3 (CFSG) unless the recogniser has a bug — the code
   also enumerates it (exact) and counts `fallback_enumeration_unexpected`; it never raises.
   With the small-scale cap (20000) the fallback also covers quotients between the cap and
   the bound. Babai's CFSG-free alternative (Sec. 13.1: UPCC Split-or-Johnson on the orbital
   configuration of a uniprimitive quotient) is not implemented.
4. **Bipartite Split-or-Johnson** follows HBD Prop. 5 (Ray-Chaudhuri–Wilson design bound and
   the Design Lemma on `V_2`) instead of Babai's Sec. 7.11 (Johnson scheme on the small part,
   local guides 7.11.2); HBD state this as an equivalent route. Changed from HBD: the arity is
   `d = 2s` with the smallest `s` such that `binom(|V_2|, s) > |V_1'|` (HBD: `s = 3⌈l⌉`, which
   satisfies the same inequality above their small-`V_2` threshold, so `d ≤ 6⌈l⌉`), and the
   small-`V_2` step is not used (`SOJParams.small_v2 = 0`): the design argument checks the
   inequality directly (`CORRECTNESS.md` §9). The small-scale preset caps `d` at 4 and
   individualises `V_2` when `|V_2| ≤ 3`. Below the papers' size thresholds a lemma's
   hypothesis can fail; the small-scale preset then falls back to individualising all of
   `V_2` (counted in `soj.STATS["individualize_v2"]`); under `Params.paper()` these fallbacks
   are unreachable (`CORRECTNESS.md` Theorem B).
5. **Case 2b** individualises `d − 1` points until the stabiliser is not doubly transitive
   (HBD Sec. 6.2) instead of Babai's Bochert / Prop. 10.1.13 argument; both are in the papers.
   When the orbital colours are tied and have valency 1 (the orbital scheme of a regular cyclic
   group of prime order), the colour classes are singletons, which do not form a coloured
   `α`-partition; the code then chooses one tied point `y` and colours each vertex by its
   distance from `x` along the colour of `(x, y)`, a discrete colouring canonical relative to
   the two choices (`soj._thin_cycle_structure`).
6. **Pullback of a large twin class** (Master Algorithm line 5, Cor. 9.0.9 "TopAction4") is
   realised by aligning the partition `{C, Γ∖C}` and restarting the recursion on
   `φ^{-1}(Sym(C) × Sym(Γ∖C))` (intransitive on `Ω`, so the Chain Rule and Reduce-to-Johnson
   take over) rather than by the dedicated window-by-window procedure of Sec. 9; the same
   recurrences apply. The dedicated Sec. 9 procedure *is* used in Case 2a (`top_action`).
7. **Align steps 6–9** (passing to the reduced `Γ'`: blocks of the equipartition or the
   `m'`-set of a Johnson scheme) are not performed by hand: after the pullback the Master
   Algorithm restarts on `φ^{-1}(Aut X)`, and Reduce-to-Johnson re-identifies the smaller
   Johnson quotient on the dominant window. This is where `recognize_johnson` is needed in
   the middle of the recursion (the top-level GI group is known to be `S^{(2)}(V)`).
8. **Design Lemma in HBD's form** (read `X_{x⃗}` off the stable `k`-ary configuration by
   substitution) rather than Babai's individualise-and-refine; HBD Prop. 4 proves this form.
9. **Group theory used as black boxes exactly as in the paper**: CFSG enters only through
   the Cameron–Maróti classification and Thm. 8.3.5 (both used as stated, and verified at
   run time where the code relies on them). The product-action reduction hands the recursion
   the preimage of the kernel `N` rather than the Johnson block system itself (Thm. 3.2.1
   names the system); the recursion recovers it as a minimal block system of `φ^{-1}(N)`, as
   in item 7.
10. **Performance.** Pure Python; inputs with more than ~20 vertices (hundreds of string
    positions) take seconds to minutes **with `Params.small_scale()`** (all timings in this
    README are for that preset unless stated otherwise; with the default preset only inputs
    up to ~9 vertices finish, Sec. 5). CFI graphs over `K_4` (28 vertices, 378 string
    positions) take about 3.5 minutes for a planted isomorphism (40 s for `|Aut| = 576`) and
    15–20 minutes for the non-isomorphic twisted/untwisted pair, because a negative answer
    explores every branch of every reduction at multiplicative cost; that pair is in the
    battery as a `slow` test (`tests/test_regressions.py`), CFI over `C_3`, `C_4`, `P_3`
    and the diamond `K_4 − e` are in the default battery. The cost is where
    the paper's analysis says it is (traced with a hook on `Solver._solve`): the 2-WL
    colouring splits the 28 vertices into 12 + 16, the Chain Rule reaches the window
    `12 × 16` on which `Sym(12) × Sym(16)` acts in product action; its quotient on the
    12 blocks of size 16 is `Sym(12)` (Johnson case `t = 1`, `G` imprimitive), so
    AggregateCertificates processes `binom(12,4) = 495` test sets with up to `4!` lifts and
    recursive window calls each, lands in Case 2b, and the reduced groups go through the same
    machinery again (after 90 s: 17 000 recursive calls, 39 aggregations, 76 Case-2b
    structures) — quasipolynomial, but large in absolute terms.
11. **`α = 2/3`** in the Extended Design Lemma and in case 2b (Babai Thm. 7.3.3 is stated for
    `α ≥ 3/4`; HBD's Design Lemma needs `α ≥ 1/2` and their Split-or-Johnson `α ≥ 2/3`,
    `CORRECTNESS.md` §8). A smaller `α` means more progress per colouring step and a smaller
    constant `b` of the time bound.
12. **Exact integer thresholds.** All comparisons with `m/2`, `n_2/3`, … are integer
    comparisons, and the `s`-th root in the Cameron-group recognition is an integer bisection,
    so the decisions are exact for every input size.
